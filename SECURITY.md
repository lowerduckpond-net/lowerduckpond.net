# Security policy

## Supported versions

The project has not made a public release. Only the current `main` branch is
eligible for security fixes.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/lowerduckpond-net/lowerduckpond.net/security/advisories/new).
Do not open a public issue or discussion for a suspected vulnerability.

Include the affected component, reproduction conditions, likely impact, and any
suggested mitigation. Remove credentials and personal or tenant information from
the report. The maintainers will acknowledge a report when it is reviewed and
will coordinate disclosure according to severity and operational risk.

This policy covers the platform source and its documented deployment model. It
does not authorize testing against production, tenant sites, third-party
services, or other users' data.

# Historical operational records

Record completed deployments and sustainability progress here. Include the
original qualified source and artifact, sanitized evidence digest, actual
acceptance result, and date. Link to requirements rather than changing them
merely to advance status. Never include credentials, state, or private logs.

Under [ADR 0029](../adr/0029-bind-qualification-to-inputs-and-live-observations.md),
non-executable Markdown, JSON, and checksum records here do not change candidate
identity. This directory must never supply executable, build, test, configuration,
or requirements inputs. Unknown file types and executable files remain inputs.
Recording completion does not require another production deployment.

# 0011: License original code under Apache-2.0

- Status: accepted
- Date: 2026-08-20

## Context

The project should be reusable and educational while providing explicit patent
terms for contributors and users.

## Decision

License original project code under the Apache License 2.0. Contributions are
accepted under the same license without a separate contributor agreement.

## Consequences

Source distributions retain the license and required notices. Third-party
assets and dependencies retain their own compatible licenses.

## Alternatives considered

MIT was simpler but lacks the same explicit patent grant. Copyleft licenses were
not selected because broad downstream reuse is an explicit goal.
